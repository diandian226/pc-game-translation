# 五款电脑版汉化补丁（清单 r3）

通过 LocaForge 的签名更新清单分发，补丁文件存放在 GitHub Releases，不向代码仓库提交游戏本体或签名私钥。

| 游戏 | 适配 PC 版本 | 补丁文件 |
|---|---|---|
| FMGWorld | 0.2.1 | fmgworld-zh-0.2.1.zip |
| 平行宇宙 | V1.3p | inaparalleluniverse-zh-1.3p.zip |
| 女神制造者 | 1.1.67 PartOne | outgrow-zh-1.1.67.zip |
| 万物生长领域 | 0.3.4.2 | realm-of-evergrow-zh-0.3.4.2.zip |
| 成长的冲动 | 0.1.1 | compulsiontogrow-zh-0.1.1.zip |

## 文件来源

- FMGWorld：现有修复版脚本，加上当前 PC 试玩版的 UI/misc.rpy 预设修复，保留 looksmaxxer 内部标识。
- 平行宇宙：项目“发布文件_退出界面修正版”的 PC 补丁，比旧试玩版更新。
- 女神制造者：现有 PC 汉化发布文件，与当前中文游戏中的对应文件逐个核对一致。
- 万物生长领域：已有 PC 外挂补丁，包括字体、显示层及教程脚本；不分发游戏 EXE 或完整游戏资源包。
- 成长的冲动：当前中文 PC 副本与英文提取脚本对比，收录改过的脚本、通用界面翻译和中文字体，不含图片、音频、视频及存档。

## 安装与验证范围

推荐使用 LocaForge 安装：先退出游戏，手动选择原游戏目录；工具会校验版本、备份被覆盖文件、处理同名旧编译脚本，可随后还原。也可手工安装，但应先完整备份原目录并保留 ZIP 目录结构；遇到旧编译脚本问题优先改用工具。

四款 Ren'Py 补丁只分发源脚本，不附带旧编译缓存。Godot 使用 override.cfg 和 zh/ 外挂包，游戏 EXE 保持不变。

发布前对每款补丁执行独立目录中的版本识别、安装后逐文件哈希核对、卸载后原文件哈希核对；不代表已在游戏中完整通关，也不代表本轮重新逐句审校。原游戏目录不用于写入测试。

本目录为 PC 补丁，不能导入安卓汉化工具。
